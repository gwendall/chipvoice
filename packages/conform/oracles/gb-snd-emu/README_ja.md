# 参照基準：Gb_Snd_Emu

Shay Green（blargg）の2005年のGame Boy APUエミュレーター、Gb_Snd_Emu 0.1.4をネイティブビルドし、レジスターログで駆動します。<https://github.com/blarggs-audio-libraries/Gb_Snd_Emu>からLGPL 2.1で同梱しています（[LICENSE](LICENSE)）。リポジトリ内の検証道具で、この参照のファイルは`chipvoice`パッケージに入りません。独自実装コードはMITです。

<a id="what-is-blarggs-and-what-is-not"></a>
## blarggのコードと本プロジェクトのコード

`gb_apu/Gb_Apu.*`、`gb_apu/Gb_Oscs.*`、`gb_apu/blargg_*.h`、`boost/`は本人の無変更コードです。次の2ファイルはこちらのものです。

- `gb_apu/Blip_Buffer.h`は本人の同名ファイルと`Blip_Synth.h`を置き換えます。2A03参照と同じ理由です。発振器は正確なクロック時刻に振幅差分を出し、一致は合成前に測るので差分を記録します。発振器は無変更でコンパイルできます。
- `main.cpp`はログを読み、APUを駆動し、声ごとに差分を合計してDACの0〜15へ写し、全変化を`<cycle> <voice> <value>`で出します。参照の矩形波／ノイズは音量×マスター音量の正負間を振れ、波形はサンプル×マスター音量の2倍です。変換はマスター7を仮定し、コーパスでも7を保ちます。

初回にシステムC++コンパイラーで`build/`へ作ります。

<a id="known-limits-of-this-oracle"></a>
## この参照の既知の限界

音のために書かれ、本人のdmg_sound ROMより古いため、食い違えばROMをより強い根拠にします。

- フレームシーケンサーはdividerのビットでなく時刻0で刻む独自256 Hz時計です。長さは実機から8192サイクルずれ、スイープは逆へ8192、エンベロープは16384早くなります。
- トリガーで周期timerを再読込せず、無音からの声は直ちに1段進みます。実機はtimerを再読込し1周期後に進むため、各音が1段ずれ、比較区間にはそれぞれ固有のシフトが必要です。
- スイープは1周期前に計算した周波数を使い、トリガー時のオーバーフローを検査せずclampします。
- DACと電源スイッチがありません。音量0は無音、包絡線レジスターは自由に書いて再始動でき、zombie modeはなく、NR52はenableをマスクするだけです。
- 波形チャンネルはトリガー直後に最初のサンプルを出します。実機は数サイクル後の初fetchまで最後の取得バイトを保持し、本人のROM 09、10、12がその時刻を検査します。
- 50／75%のデューティーパターンはPan Docsから2／1段回転し、該当音の時間だけをずらします。
- ノイズレジスターは実機同様15ビット全1から始め、両幅とも実機列を出します。ROMで検査しない短い列も比較で確認します。
