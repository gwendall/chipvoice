Shay Green（blargg）の2A03 APU参照、Nes_Snd_Emu 0.1.7をネイティブビルドし、レジスターログで動かします。<https://github.com/blarggs-audio-libraries/Nes_Snd_Emu>からLGPL 2.1で同梱しています（[LICENSE](LICENSE)）。リポジトリ内の道具で、ここの参照ファイルは`chipvoice`へ入りません。独自実装コードはMITです。

<a id="what-is-blarggs-and-what-is-not"></a>
## blarggのコードと本プロジェクトのコード

`nes_apu/Nes_Apu.*`、`nes_apu/Nes_Oscs.*`、`nes_apu/blargg_*.h`、`boost/`は本人の無変更コードです。次の2ファイルはこちらのものです。

- `nes_apu/Blip_Buffer.h`を置き換えます。発振器はサンプルでなく正確なCPU時刻の振幅差分を出し、シンセが帯域制限してサンプルバッファーにします。一致はその前で測るので差分だけを記録し、発振器は無変更でコンパイルします。
- `main.cpp`がログを読み、APUを動かし、各声の差分を合計して全変化を`<cycle> <voice> <value>`で出します。

初回にシステムC++コンパイラーで`build/`へ作ります。

<a id="known-limits-of-this-oracle"></a>
## この参照の既知の限界

2005年の実装で、現在のnesdevの一部の知見より古いものです。信頼できる部分とできない部分はシートへ記載します。

- フレーム列は補正付き1段7458サイクルで、nesdevの7457、14913、22371、29829とは異なり、段が2サイクル遅れます。後年のblargg本人のROMはハーネスでサイクル単位に検査しnesdevに一致するため、ずれているのは参照です。
- ノイズは`1 << 14`から始まり、ビット0が*立つ*と音量を出します。文献と極性が逆で、ミュート中にレジスターを正確に刻みません。
- ビット7付き`$4017`は書込0〜1サイクル後にフレームを刻みますが、実機は3〜4です。後年の`apu_test`が正確に確認します。滑らかなビブラートは周期境界ごとにこの時計を強制し、その間にパルスtimerが再読込されると、残りの音全体でエッジが数サイクルずれます。
- 三角波は長さ／linearカウンター再読込時に即進みますが、実機は次のtimer満了まで待ちます。また列の2つの0の別側から始まります。実機は三角波位置をリセットしないため、最初の音から永久に2段ずれます。
- `reset()`が全声へ`$4003`を書き、包絡線startを立てたままにして、初フレーム時計が全減衰を15へ読みます。減衰前に包絡線モードへ入れると、ここでは15、実機では0で鳴ります。そのためコーパスは0.1秒後から始めます。
- DMCの出力部は初周期の残りビット1で始まり、nesdevとMesenは8なので、最初のサンプルバイトが1ビット周期ずれます。さらに`$4011`書込はポップ音のためDAC表で振幅を調整し、その後のレベルがレジスター値ではなくなります。

したがってパルス、三角波、DMCステップの参照とし、ノイズは包絡線と長さの証人には使いますが、ビットパターンの基準にはしません。
