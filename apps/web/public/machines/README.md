# Console marks

The public demo uses Japanese console branding. Assets are self-hosted, unmodified SVG downloads from Wikimedia Commons (retrieved 2026-09-06). Their file pages document the vector authors, upload history and PD-textlogo designation. Trademark rights remain with Nintendo and Sega; these marks identify the emulated systems and imply no endorsement.

These compact, transparent vectors retain the original console identities at button size. Nintendo’s Classic Mini product pages were also checked, but their product logos identify the later mini editions. Commons provides the original marks with a documented file history. Images use `object-fit: contain`, never CSS masks or recolouring. Buttons contain only the artwork; `aria-label`, `title` and `aria-pressed` provide names, chip details and selection state without visible captions.

## Archived marks

`nes.svg`, `gb.svg`, `md.svg`, `snes.svg`, `c64.svg` remain from [HVR88 / Monochrome Gaming Logos](https://github.com/HVR88/Monochrome-Gaming-Logos), revision `7eb7ddb7246fa5c39b71d5136e7a527bac03fb7f`. Original filenames: `nintendo_nes.svg`, `nintendo_gameboy.svg`, `sega_megadrive.svg`, `nintendo_snes.svg`, `commodore_64.svg`; shortened filenames only. See the collection’s [usage notice](https://github.com/HVR88/Monochrome-Gaming-Logos#usage-disclaimer). Attribution is retained on About.

C64 is hidden through `DEMO_MACHINES`, not removed from `MACHINES`, schemas, saved documents, the SDK or the evaluation corpus. Restoring it is a presentation change.
