# Console marks

Identification artwork from [HVR88 / Monochrome Gaming Logos](https://github.com/HVR88/Monochrome-Gaming-Logos), revision `7eb7ddb7246fa5c39b71d5136e7a527bac03fb7f`.

Unmodified SVGs: `nintendo_nes.svg`, `nintendo_gameboy.svg`, `sega_megadrive.svg`, `nintendo_snes.svg`, `commodore_64.svg`; shortened filenames only. Loaded locally as CSS masks, with visible text labels.

Original designs and trademarks belong to their respective owners. These recreations identify the emulated machines and do not imply affiliation or endorsement. The collection requests attribution and a link back, also provided in the demo footer. See its [usage notice](https://github.com/HVR88/Monochrome-Gaming-Logos#usage-disclaimer).

Multi-tap's frontend was checked first: its `/api/system-logo` proxies authenticated ScreenScraper media. This demo bundles five static vectors instead of requiring that service at runtime.
