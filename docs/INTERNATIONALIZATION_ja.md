# 英語と日本語のWebサイト

<p align="center">
  <a href="INTERNATIONALIZATION.md">English</a> &bull;
  <a href="INTERNATIONALIZATION_ja.md">日本語</a>
</p>


<a id="specification"></a>
## 仕様

公開サイトを英語と日本語にします。英語は既存URL、日本語は`/ja`です。サイト自身のUI、アクセシブルなラベル、読込／エラー、内蔵音楽の説明と証拠、ページと共有メタデータをすべて対象にします。言語変更でページ、query、hash、読込MIDI、作曲下書き、再生中音声を保ちます。既存の視覚的個性とモバイルで読める文字を維持し、Domaniの方式に従う単純なJSONカタログを使います。

<a id="architecture"></a>
## アーキテクチャ

- カタログは`apps/web/src/i18n/messages/en.json`と`ja.json`。画面の言葉で検索できるよう、キーは英語原文です。新しい文言は完全な文と名前付き`{placeholders}`で書きます。
- `core.ts`が言語パスと翻訳を扱い、UIの補間は明示的です。`source-templates.json`の正規文だけを`t.source()`の原文照合に使います。「{elapsed} of {duration}」のような一般UI文が無関係なエラーへ一致するのを防ぎ、演奏文書、レンダーキャッシュ、音声effect依存へlocaleを持ち込みません。有界な翻訳キャッシュは音声ループと無関係です。
- `[locale]`が単一のNext.jsルートツリーで、両言語を事前描画します。`proxy.ts`が英語URLを内部的に`/en`へ書き換え、`/en`自身は元の正規URLへ戻します。API、音声、ダウンロード、機械可読リソースは安定URLを保持します。`skipProxyUrlNormalize`でループバックも含む要求元を保ち、ローカル書換が外部要求／リダイレクトループにならないようにします。
- `I18nProvider`が選んだ辞書を供給します。切替は他言語を必要時に読み、ネイティブhistoryを更新して楽器をアンマウントしません。戻る／進むも言語を復元します。辞書取得失敗では楽器を保って再試行文を出し、ページを再読込しません。内部リンクはlocale対応の`Link`を使います。
- サーバーメタデータとその場のhead更新はページカタログを共有します。canonical、`hreflang`、Open Graphのlocale／title／description、Twitter、sitemap、共有カード画像に言語を反映します。
- サインイン要求はメールと引換リダイレクトを通じlocaleを保ちます。認証の意味とAPIエラー識別子は変更しません。

<a id="content-boundary"></a>
## 翻訳する内容の境界

公開音声レポートの証拠段落も含め、サイト自身の文章と表示ラベルを翻訳します。利用者が書いた曲名、MIDIファイル名、トラック名、音符、録音は内容として保持します。音楽トークン、楽器／プログラムID、原典ハッシュ、URL、API／JSONプロパティー、実行JavaScript識別子は正規表記のままです。翻訳すると音楽や利用側を壊します。英語／母語の言語名、製品／ライブラリ名、MIDI、BPM、LUFSなどの単位は識別可能に保ちます。リポジトリ文書と`/skill.md`／`/llms.txt`は開発者リソースで、サイトの代替言語ページとは別です。

内蔵作曲タイトルはUndo／Redoのスナップショットに表示の由来を持ちます。タイトル編集でその由来を外し、読み込み、復元、共有のタイトルはカタログキーと偶然一致しても利用者の内容として扱います。フラグは保存する音楽文書に含めません。

日本語共有カードのフォントは`apps/web/assets/fonts`へサーバー用として同梱します。実行時にフォント提供者へ通信せず、サイトもダウンロードしません。同ディレクトリに出典、ライセンス、再現方法があります。

<a id="validation"></a>
## 検証

`pnpm --filter chipvoice-web build`の後、`pnpm --filter chipvoice-web test`を実行します。`test-i18n.mjs`がカタログ一致、プレースホルダー一致、UI／アクセシビリティの文字列網羅、公開原典／証拠の網羅、ルート／テンプレート挙動を検証します。ブラウザー確認は実描画、音声連続性、読込、作曲状態、メタデータ、日本語共有、モバイル配置を見ます。結果と画像は日付付き評価レポートを参照してください。
