<a id="status-and-objective"></a>
## 状態と目的

2026-09-07、Zelda/Mega Drive のバランスに関する利用者の指摘を受けた計画です。
`chipvoice@0.16.1` として公開し、自動リリース検証は完了しました。人間の試聴と実機による受け入れ確認は未完了です。[API と制約](MIXING-API_ja.md)、[開発評価](evals/AUTOMATIC-MIXING-POLICY-2026-09-07_ja.md)を参照してください。今後のリリースと機能でも、音と移植品質を優先します。

作曲、インポート、生成した音楽を対象に、決定的でローカル動作する汎用の編曲／ミックスを作ります。
有名曲はテスト用であり、曲別ミックス設定にはしません。本番ポリシーでタイトル、ファイルハッシュ、曲 ID による
分岐を禁止します。出典管理や収録曲の識別テストでは識別子を使えますが、ポリシーの外に置きます。

<a id="contract"></a>
## 契約

- 音源動作、本体出力、楽器対応／校正、音楽的ミックスを分けます。ゲイン調整前に確認された出力の欠陥を直します。
- ネイティブ再生は元のレジスター命令と音楽的ミックスを保持します。エミュレーター／出力の修正は適用されます。自動リミックスは明示的に選びます。
- 移植は対応可能な作者の表情と明示的な上書きを保持します。ベロシティーは音色にも影響するため、ミックス調整と区別します。全声部を均等化せず、旋律が常に主役とは仮定しません。
- SDK、worker、オフライン描画、ゲーム統合は小さなインターフェースの共通モジュールを使用します。判断と診断を返し、利用側にルールを複製しません。
- 既知の楽器は必要な条件で事前校正します。未知の楽器は有限の測定か明示した保守的フォールバックを使い、無制限に描画しません。
- 実際の声部割り当て、レジスター分解能、共有資源、内部の余裕を考慮します。非線形ミキサーでは分離録音の和が原音と一致しないため、全体も測定します。
- 全曲準備とライブ生成の情報範囲を明示します。ライブは有限先読みと滑らかな包絡で処理し、未知の曲全体を要求しません。外部審査、サンプルごとのポリシー割り当て、判断ごとの全曲解析は不要とします。
- 決定性は対応入力、エンジン、ポリシー／プロファイル版、描画条件を固定した場合の判断と検証済み環境での反復出力を指します。環境間のビット一致は別途検証し、仮定しません。
- 正しさの必須条件、音響的診断、条件を管理した聴取を組み合わせます。あらゆる音楽の良さを保証する評価ではありません。

<a id="execution-and-review-batches"></a>
## 実行とレビューの単位

1. MIX-01〜03、MIX-12 の初期評価器、MIX-14 の基準と予算を先に用意します。MIX-04 の調査／修正と MIX-05 の監査を行い、未解決の出力欠陥を調整で隠しません。
2. MIX-06〜10、続いて MIX-11 を実装し、MIX-12 を並行して拡充します。調整用の曲だけでなく、固定した合格条件で MIX-13 と MIX-14 を検証します。
3. MIX-15〜18、最終英日文書、公開物と利用側プロジェクトの確認を完了します。

実装と検証を PR #40 にまとめ、PR #41 で SDK の公開ワークフローを修正しました。
独立したレビューと証拠は上記にリンクしています。実機と人間の試聴の証拠は取得するか未完了と明示し、
自動検証だけでそれらの受け入れ条件を完了にはしません。

<a id="deferred-directions"></a>
## 延期する方向

新音源、C64 の再表示、完全な DAW、Storybook は対象外です。段階的描画、追加キャッシュ、音源別パッケージ入口は
測定で必要性を判断する後続作業であり、自動的な前提条件ではありません。より豊かなゲーム状態に応じた音楽と
オリジナル曲の追加は汎用移植の検証後に進めます。音楽生成やミックスに常時外部モデルサービスは要求しません。

<a id="cold-review-follow-up-0162"></a>
## コールドレビュー後の対応（0.16.2）

以前のコーパスが成功していても、MIX-09～13 には見落としがありました。
SNES の内部加算・エコーの共通保護、元から無音の音符の割り当て分離、
役割ごとの可聴区間密度、フレーズと楽曲の共有ハードウェア制約、FM ドラムを
修正しました。MIDI の役割は全音符から推定し、確信度を示してプレイヤーで
修正できます。無音による音声占有、トラックの分割、過大フレーズ、
リカバリー中の実際のレジスタ音量を回帰テストに追加しました。
評価は楽曲全体を対象にし、音響的な合否基準と別構造の検証曲を追加しました。

詳細は[評価記録](evals/AUTOMATIC-MIXING-COLD-REVIEW-2026-09-07_ja.md)を参照。
人間による試聴と実機スマートフォン・Safari の確認は別の課題です。
リリースが残る SNES フレーズは、スケジュール前に共通の区間で準備する必要が
あり、すでに予定した前のフレーズを後から自動修正する API ではありません。

<a id="native-timbre-follow-up-0163"></a>
### ネイティブ音色の追補（0.16.3）

完了：SNES 標準音色のドライ化と内部音量予算 120、FM 基音と音量変化の実測、
音色 ID と MIDI 番号の分離、DAC の繰り返し発音とキック／スネア推定、表示音高の
修正、試聴ラボの SNES 6 ケースの再評価。元のゲーム機の録音は変更していません。

残る制限：FM の測定は 2 音高と有限の音量区間で、全音高の完全なエンベロープでは
ありません。移植先の標準音色、余韻、ステレオは近似です。DAC 分類はヒューリスティックで、
静かな候補を別途記録します。人による比較試聴と実機での確認は未完了です。
[音色評価](evals/PORTABLE-TIMBRES-2026-09-07_ja.md)を参照してください。
