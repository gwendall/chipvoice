# メガドライブ：YM2612 + SN76489 (`md`)

<p align="center">
  <a href="md.md">English</a> &bull;
  <a href="md_ja.md">日本語</a>
</p>


メガドライブは4オペレーターFMを6チャンネル持ち第6にDACを備えるYamaha YM2612と、映像チップ内の矩形波3音＋ノイズのTexas Instruments SN76489を使います。方法は[CONFORMANCE.md](../CONFORMANCE_ja.md)を参照してください。

| | |
| --- | --- |
| **機種** | Mega Drive、Genesis（NTSCマスター53693175 Hz、YM2612は1/7、PSGは1/15） |
| **状態** | **作業中**：全スクリプトのFM出力はダイ解析由来の参照と一致。全役割を再生可能。PSG参照は未導入、アナログ段は未測定 |
| **コア** | YM2612はNuked-OPN2の逐行移植（`packages/chipvoice/src/chips/md/ym2612.ts`）、SN76489はSMS Powerの資料から実装（`sn76489.ts`） |
| **コアのライセンス** | `ym2612.ts`はNuked-OPN2由来のLGPL 2.1。独自コードはMIT。パッケージに両方を表示 |
| **更新日** | 2026-09-04、手動および`conform` |

**数値の意味。** Nuked-OPN2はYM3438のダイを読み解いた実装で、本コアはその移植です。8アルゴリズム×3帰還量、エンベロープ各段とキースケール、デチューンと各倍率、全LFO速度と両感度、SSG-EGの8形状、チャンネル3特殊モード、DACで、FM6ボイスがサイクル単位に一致します。全エッジが正確で不一致なし、全区間のシフトはゼロです。原文には曲の少数サイクルの差への記述も残っていますが、最新表の曲は100%です。これはダイ解析から得られる範囲での一致で、本プロジェクトで最も強い検証です。

PSGは参照実装がなく比較対象外です。速度、減衰、両ノイズ系列は数式テストで固定します。

<a id="driver-coverage"></a>
## ドライバーの対応範囲

`packages/chipvoice/src/chips/md/driver.ts`の`MdDriver`を`test/md-driver.mjs`で検証します。リードはFM 1、ベースはFM 2、和音はPSG 1、ドラムはtone 3を時計とするノイズです。

| ボイス | 使用する機能 | 使用しない機能 |
| --- | --- | --- |
| fm1、fm2 | 意図ごとにパッチを各チャンネルへ1度ロード。フレームごとのblock／F-numberとキャリアtotal level、キーオン／オフ | LFO、SSG-EG、チャンネル3モード、DAC、パッチのキースケール、残り4チャンネル |
| psg1 | フレームごとの周期と減衰 | psg2／psg3の音程付き使用 |
| noise | 2A03の16レートに対応するtone 3時計の白色ノイズ、フレームごとの減衰 | 周期ノイズ、固定3レート |

## 既知の差異

| 内容 | 意図的か | 理由 | 影響 |
| --- | --- | --- | --- |

<a id="power-on-state"></a>
## 電源投入状態

`reset()`はNukedの`OPN2_Reset`です。全オペレーターがエンベロープ底部のリリース状態、倍率1、左右パン有効、PSGは全減衰器で無音です。ドライバーはゲーム同様、LFOをオフ、チャンネル3を通常、DACと全キーをオフにします。
