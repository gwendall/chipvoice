# ゲームボーイAPU (`dmg`)

<p align="center">
  <a href="dmg.md">English</a> &bull;
  <a href="dmg_ja.md">日本語</a>
</p>


DMGのCPUに内蔵された音源です。矩形波2音（第1は周波数スイープ付き）、RAMの4ビット×32サンプルを再生する波形チャンネル、ノイズ発生器を備え、左右の音量制御を通してステレオ混合します。方法は[CONFORMANCE.md](../CONFORMANCE_ja.md)にあります。

| | |
| --- | --- |
| **機種** | Game Boy（DMG）、4194304 Hz |
| **状態** | **作業中**：全テストROM成功、全ボイスをドライバーで使用。参照実装は限定的で、アナログ段は未測定 |
| **コア** | 独自の`packages/chipvoice/src/chips/gb/dsp.ts`。Pan DocsとblarggのGame Boy Sound Operationに基づく |
| **コアのライセンス** | MIT |
| **更新日** | 2026-09-04、手動および`conform` |

**数値の意味。** 先頭列だけでなく末尾列を見てください。各ボイスのほぼ全区間は、区間ごとの一定シフトでエッジ時刻と値が参照と揃います。矩形波のデューティと速度、上下両方向のエンベロープ、3段階の波形出力、両ビット幅のノイズ系列を確認できます。一致サイクル数が低いのは、音の開始規約が系統的に異なるためです。参照はトリガー直後に最初のステップを出しタイマーを再ロードしませんが、実機は再ロード後1周期待ちます。フレーム時計も分周器のビットでなく時刻ゼロで動き、50%／75%デューティの配列も回転しています。その一定ずれだけで各サイクルが不一致に数えられます。

残りの未対応エッジには、参照にないゾンビエンベロープ、周波数適用が1周期遅いスイープ、直ちに初サンプルを出す波形チャンネルが含まれます。[参照README](../../packages/conform/oracles/gb-snd-emu/README_ja.md)に列挙しています。これらはPan Docsやサイクル単位のROM検査に対するchipvoiceの逸脱ではありません。ROMは成功しています。この参照はROMが検査しない短周期ノイズの形とエンベロープの段階を確認できます。強い参照の追加はP3-4です。

<a id="driver-coverage"></a>
## ドライバーの対応範囲

`packages/chipvoice/src/chips/gb/driver.ts`の`GbDriver`を`test/gb-driver.mjs`で検査します。リードはpulse 1、和音はpulse 2、ベースは波形、打楽器はノイズです。

| ボイス | 使用する機能 | 使用しない機能 |
| --- | --- | --- |
| ch1、ch2 | 全4デューティ、初期音量を変更ごとに再トリガー、トリガーなしの周波数変更、DACを有効にした音量0の無音 | スイープ（無効化）、ハードウェアの減衰、長さカウンター、DAC無効化 |
| ch3 | 停止中の波形RAMロード。標準は三角波、または楽器独自の32サンプル。3段階音量、トリガーなしの周波数変更 | 長さカウンター、再生中RAM書き込み／再トリガー |
| ch4 | 2A03の16レートをdivisorとshiftへ変換、両ビット幅、音量テーブルをハードウェア減衰へ近似、発音中レート変更 | 上昇エンベロープ、長さカウンター、発音中再トリガー |
| NR50、NR51 | 起動時に1回設定：左右7、全ボイスを両側へ | パン、マスター音量変更 |

<a id="known-deviations"></a>
## 既知の差異

| 内容 | 意図的か | 理由 | 影響 |
| --- | --- | --- | --- |
| 左右ルーティングとマスター音量はデジタルトレースに含めない | はい | トレースはDACへの入力。NR50／NR51はその後の出力段 | 一致率のみ。実出力には適用 |
| トリガー後の初波形フェッチが6サイクル遅れる | いいえ、ただしどちらか未確定 | blarggの記述に従い、2サイクル以内の差に敏感なROM 09／10／12が成功 | 各波形音の最初のサンプル |
| 再トリガー時RAM破損は個体差のある現象の1モデル | はい | SameBoyによると大半のDMG-Bが該当し、一部は異なる。ROM 10はこのモデルを検査 | 再生中再トリガー後のRAM |
| CGB固有の差は未実装 | はい | 対象はDMG。`cgb`なら差を切り替えてコード共有可能 | Game Boy Colorの動作 |

<a id="power-on-state"></a>
## 電源投入状態

`reset()`は起動音を除くブートROM終了後相当です。電源オン、レジスタと波形RAMはゼロ、フレームシーケンサーは最初の時計直前、ノイズは全ビット1です。実ブート音が残すpulse 1設定と左右マスター音量7は、ROM実行前にハーネスが書き込みます。
