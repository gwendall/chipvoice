<a id="cause-and-correction"></a>
## 原因と修正

PR #38 は表示上の NSF トラック 2（0 始まりでは 1）を選び、Overworld と表示していました。
本実装も独立リファレンスも同じ別の曲を再生していました。コマンドの一致はエミュレーションの
整合性を示しますが、選んだ曲が正しいことは証明しません。ユーザーの指摘は正しく、こちらの選曲ミスでした。

固定した NES NSF の Overworld は表示上のトラック 3（0 始まりでは 2）です。ソースのハッシュは
`ebd279307c158b9561c254e55eaf683c3ea65736d1303144ed56ff89a92a0364` のままです。
修正版はイントロと 1,920 フレームの完全なループ 1 周を含みます。全長は 38.1705 秒、
ループ開始は 6.2231 秒（フレーム 373〜2293）です。移植用の観測結果は元の 4 声部、592 音です。

<a id="identity-before-parity"></a>
## 一致の検証より先に曲を特定する

独立した Colletti の MIDI リファレンス（`scores/references/zelda.json`）の 16 拍目からの
確認済みフレーズは、連続する同音をまとめるとピッチクラス
`10, 5, 10, 0, 2, 3, 5, 6, 8, 10, 8, 6` になります。新しい検証は移植用の音符抽出器を使わず、
パルス音源のタイマーレジスターから直接音列を読み取り、キャプチャーと公開前にこのフレーズを要求します。

実際の旧ソースでは旋律の再現テストと追加した `pnpm arrangements:check` が失敗しました。
15 曲の各先頭 1,800 フレームを調べた結果、このフレーズがあったのは表示上のトラック 3 だけでした。
修正版は成功し、無関係な正規の Mario キャプチャーでは失敗します。固定フレーズ自体も独立した
MIDI リファレンスに照合しています。

これは収録曲専用の曲名照合です。オクターブ差は許容しますが、調と音順は保持します。
すべてのリズム、音色、フレーズ、実機出力特性を証明するものではありません。全コマンドの一致は
別の検証です。選択トラックはキャプチャーとオラクル検証で共有し、公開時にもマニフェストと照合します。

<a id="independent-verification"></a>
## 独立した検証

固定リビジョンの Game_Music_Emu を新たにビルドし、トラック番号 2 を独立して記録しました。
18,137 件の演奏コマンドのアドレス、値、順序、絶対 CPU サイクルがすべて一致しました。
順序付きコマンドの SHA-256 は
`ffea3e7c6cdcd83e89647ee6210c6dcd9cd2db3ba4bbf0687fd2544712506a21` です。
1,920 フレームの全ループも完全に反復します。誤った旧トラックのオラクルは再利用していません。
再現コマンドは[アレンジメントガイド](../../scores/arrangements/README_ja.md)にあります。

<a id="qualification"></a>
## 品質確認

Zelda の 4 機種の録音と独立リファレンスを正しいソースから再生成します。公開検証は曲の特定、
選択トラック、オラクル、録音ハッシュ、デコード後の長さを結び付けます。ブラウザ回帰テストは
配信されるネイティブソースの旋律、評価済み録音のハッシュ、0:38 の表示時間、実際の A/B 出力を確認します。
デスクトップとモバイルのスクリーンショット、動画も保存します。最初の 12 秒の両録音のスペクトログラムも、
ソースの時間位置を変えずに確認しました。冒頭のリードのピークは両方とも 465.7 Hz
（0.1〜0.45 秒の FFT、ほぼ B♭4）です。この部分的な確認は、旋律と全コマンドの検証を補うものです。

ローカル証拠は `.artifacts/zelda-selection/`（修正前後のログ、曲の走査、新しいキャプチャーと評価）と
`.artifacts/native-songs/browser/`（画像、動画、ブラウザ出力測定）にあります。ダウンロードした
NSF 実行ファイルとオラクルビルドはローカルに残します。旧レポートの Zelda の曲名に関する主張を
明示的に撤回し、Mario と Sonic の証拠は変更しません。
