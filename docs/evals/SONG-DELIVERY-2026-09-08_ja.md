# エージェントの楽曲納品評価

<p align="center"><a href="SONG-DELIVERY-2026-09-08.md">English</a> &bull; <a href="SONG-DELIVERY-2026-09-08_ja.md">日本語</a></p>

<a id="change-and-acceptance"></a>

## 変更と確認条件

実際のチャットで、エージェントがスキル内の例と同じ八小節・六パートの曲を作ると宣言しました。意図の表明であり、出力をコピーした証拠ではありません。スキル0.13.0では、オリジナル作曲、曲全体の音声納品、許可された公開を分けました。参考曲は任意のリンクに移し、本文の実行コードはエージェント自身のプロジェクトをレンダリングします。短いループの依頼を尊重し、公開にはユーザーの意図と認証情報が必要です。所有者の連携承認待ちでもローカル作曲を続けます。

<a id="executable-checks"></a>

## 実行可能な検証

本番ビルドに成功しました。`test-agent-guide.mjs`は任意の参考曲を取得し、配信スキルそのもののレンダリング用コードを検出された全機種で実行しました。WAVはSDKの直接生成とバイト単位で一致しました。48秒の技術用フィクスチャーで、サーバーのプレビュー上限を超えて曲全体が生成されることを確認しました。この反復フィクスチャーは音楽的展開の参考例ではありません。厳密モードではボイス不足をエラーとして維持します。HTTP手順を使い捨てローカルDBで実行し、固定WAVとタグ付きMP3を取得しました。ブラウザーの信号プローブでRMS 0.05246を確認し、JavaScriptエラーとモバイルの横方向のはみ出しはありませんでした。デスクトップとモバイルのスクリーンショットを確認し、英日文書のナビゲーションと見出し検査にも合格しました。

ローカルの証跡は`.artifacts/agent-guide/`にあります。SDKとDSPは変更していません。同梱のCodexスキル検証器は、このWebスキルに以前からある`compatibility`と`homepage`を拒否しました。その限定的なフロントマター規則は、このHTTPスキル形式の検証器ではないため、既存フィールドを維持しました。

<a id="independent-composition-trial"></a>

## 独立した作曲試行

別のエージェントに、修正後のスキル、「crée moi une chanson via le skill Chipvoice」という依頼、ローカルSDKと機能カタログ、隔離された一時ディレクトリだけを渡しました。公開、アカウント操作、試聴ツール、チャットへの添付は利用できません。エージェントはNES向けに**Les toits après la pluie**を新規作曲しました。128 BPM、32小節、60秒、四パートで、導入、主題、ブリッジ、展開した再現、終止を含みます。参考曲と実装ソースは読みませんでした。

| 観測 | 結果 |
| --- | --- |
| ソース／発音された音符 | 599／599、厳密な割り当て |
| 計測区間 | 44,100 Hzで60秒全体 |
| ピーク／RMS | 0.235754／0.046789 |
| クリップしたサンプル | 0 |
| 再生成 | WAVがバイト単位で一致 |
| ローカル成果物 | プロジェクト、評価、WAV、MP3 |

三角波の音量制約を確認した後、ブリッジのベースを短くして間隔を広げました。音色、打楽器エフェクト、タイミング、ミックスの診断は残しました。実際には聴いておらず、この試行ではファイルを添付できないことを明示しました。ファイル生成は確認できましたが、遠隔チャットへの添付や主観的な音楽品質を検証したことにはなりません。

追加の判断だけの三ケースでは、10秒ループの指定を尊重し、ページ作成を依頼された未認証状態では作曲を続けながら連携を案内し、HTTPしか使えない状態ではサーバー音声を得る前に公開許可を求めました。判断の試行であり、認証APIを実行したテストではありません。実際の連携APIは既存のアーティストライフサイクルテストで確認します。

ローカルの試行証跡は`.artifacts/song-delivery/trial/`にあります。WAV SHA-256：`a93af4fc918575d0da2aab6c1ccf0f07f2731124e55a8ea792686cb0c3087b72`。一回の独立試行は有用な行動上の証拠ですが、すべてのエージェントが指示に従い、良い曲を作る保証ではありません。
