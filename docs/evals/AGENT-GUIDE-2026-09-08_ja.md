# エージェント作曲ガイドの評価

<p align="center"><a href="AGENT-GUIDE-2026-09-08.md">English</a> &bull; <a href="AGENT-GUIDE-2026-09-08_ja.md">日本語</a></p>

エージェント向けの入口は完全な`MusicProject`のPerformanceを優先する構成になりました。機種の能力は別の手書き表ではなく、エンジンから生成します。実行例は八小節・六パート、110音のオリジナル合奏で、44100 Hz、16秒の音声を生成します。

<a id="executed-workflow"></a>

## 実行した手順

`apps/web/test-agent-guide.mjs`は配信されたスキルを読み、JavaScriptを抽出して検出された全対象で実行します。続いてBashの公開手順を抽出し、使い捨てのローカルデータベースに対して実行します。プロジェクト本体の検証、余分なラッパーや未知フィールドの拒否、認証、冪等性キーの保持、競合、ポーリング、バイト単位で一致する固定WAV、リミックスの親子関係を確認します。HTTP検出マニフェストのスキーマ参照と認証宣言も検査します。

仮想の追加対象により、文書生成が機種数を固定していないことを確認します。配信された機能応答はエンジンから生成した文書と比較します。ブラウザーエディターへのインポート、実際のGeneral MIDIプログラムの表示、発音の計測、デスクトップとモバイルのスクリーンショットも行います。この検査は通常のWeb CIに含まれ、成果物をアップロードします。

別途、npmから`chipvoice@0.17.0`をインストールした新しい利用側ディレクトリで例を実行しました。そのプロジェクトを本番サイトにローカルインポートして再生し、本番アカウントや公開物は作成していません。ブラウザー信号のRMSは約0.048で、JavaScriptエラーはありませんでした。架空のコミュニティ投稿を増やさずに、ローカルのHTTP公開テストを補完しています。

<a id="audio-observations"></a>

## 音声の観測結果

| 対象 | ソース音符 | 再生音符 | 省略 | RMS | ピーク |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2a03 | 110 | 87 | 23 | 0.03761 | 0.19050 |
| dmg | 110 | 87 | 23 | 0.03935 | 0.25092 |
| md | 110 | 110 | 0 | 0.04087 | 0.19087 |
| snes | 110 | 110 | 0 | 0.04965 | 0.20939 |
| c64 | 110 | 77 | 33 | 0.03954 | 0.62063 |

同じエンジンとサンプルレートでは、すべてのレンダリングがバイト単位で再現します。サンプルは有限値で、無音でもクリッピング状態でもありません。全音符の保持は音色の保持を意味しません。Mega Driveの結果には音色の置き換えと未校正ミックスが含まれます。他の結果にも音色、ハードウェアのミックス、バスタイミングの制限が記録され、隠されません。

Famicom向けの明示的な縮約では、補助的な金管と対旋律を取り除き、弦の同時和音を時間指定のアルペジオに変更しました。音符の省略なしで収まり、32音のメロディーをすべて保持します。別の32音同時発音ケースは構造的には有効ですが、厳密なレンダリングでは失敗します。損失を許可すると省略の記録が返ります。文書の正しさ、ハードウェア上の再生可能性、音楽的判断を区別する検査です。

<a id="review-and-corrections"></a>

## レビューと修正

規約レビューでは、旧エンドポイントの認証メタデータ不足とツールマニフェストの解決できないコンポーネント参照を検出しました。両方を修正し、回帰検査を追加しました。仕様レビューでは、応答の固定チップ一覧と実際のキット楽器を使っていない打楽器の検出を見つけ、エンジンのデータから導出するようにしました。

本番バンドルでは、JSONから読み込んだ音域の浮動小数点値が短縮される問題も発生しました。機能エンドポイントは生成した元のJSONテキストを返し、数値とコンテンツハッシュの一致を保ちます。ブラウザー評価では、短いプリセット一覧にないインポート楽器がPulseと表示される問題も発見しました。ソースと音声を変えず、実際のプログラム番号を表示するように修正しました。

<a id="reproduction-and-limits"></a>

## 再現方法と限界

`pnpm --filter chipvoice-web build`でビルドし、`pnpm --filter chipvoice-web test`で使い捨てサーバーとデータベースを使うWebテストを実行します。個別の検査は`apps/web/test-agent-guide.mjs`で、ローカル以外のHTTP対象を意図的に拒否します。音声、レポート、スクリーンショットは`.artifacts/agent-guide`に生成し、コミットしません。作曲ソースは[compose-project.mjs](../examples/compose-project.mjs)です。

これは実行可能文書の予行演習であり、独立した言語モデルのベンチマークではありません。音楽の構成はソースから確認しています。信号計測や画面確認では、主観的な良さ、リアルなオーケストラ音色、ゲーム原音への忠実性は証明できません。DSPと校正アルゴリズムは変更していません。将来のコンソールも、プロジェクトAPIに登録する前にエンジンの実装と検証が必要です。
