<a id="purpose"></a>
## 目的

chipvoice.dev は、すぐに遊べるライブラリの実演です。作曲経験のない人も探索を楽しめ、開発者は作った音を自分のプロジェクトへ持ち帰れます。

小さな音楽コンソールとして、聴く、機種を変える、効果音を鳴らす、曲を変える、共有する、仕組みを見る、という流れを提供します。再生や下書きの作成にアカウントは不要です。最初の画面は楽器に使い、資料とアカウント管理はその後に置きます。

代表的な体験は、同じフレーズを公開中の4機種で聴き比べ、効果音が曲のボイスを一時的に借りる様子を目と耳で確かめることです。

<a id="first-visit"></a>
## 初回訪問

1. 新規訪問ではマリオを読み込みます。保存済み下書きと共有楽譜を優先します。Play、または曲・機種への最初の操作で音を開始します。ページ表示だけやTab移動では鳴らしません。
2. ファミコン、ゲームボーイ、メガドライブ、スーパーファミコンをロゴで選択できます。C64は既存楽譜を引き続き再生できますが、選択一覧では非表示です。機種を変えても曲中の位置と編集内容を維持します。
3. リード、和音、ベース、ドラムの4つの役割を音楽に合わせて表示します。
4. Jump、Coin、Laser、Explosionのパッドで音と小さな視覚効果を起こします。ボイスを借りる場合は実際の中断と復帰を表示します。
5. 役割のミュート、音色変更、数音の編集を試し、その結果を共有するか、楽譜と実行可能なコードをコピーできます。

<a id="v1-the-whole-experience-kept-small"></a>
## V1：小さく完結する体験

<a id="four-public-consoles-and-familiar-melodies"></a>
### 公開する4機種と親しみのあるメロディ

日本版ロゴ4つを常時表示し、選択状態を明確にします。切り替えでも再生位置を維持し、停止中は停止を維持します。読み込み中の連続操作でもプレーヤーを重複させず、古い非同期処理の完了を適用しません。

出典を確認したマリオ、ゼルダ、ソニックのメロディを先頭に置きます。オリジナルのOverworld、Boss Fight、Midnightは補助的な開閉領域へ移します。全曲を全機種で再生でき、比較に必要な旋律を保ちながら各機種固有の編曲を使います。機種専用曲の追加は後続です。

<a id="a-living-display"></a>
### 音楽に反応する表示

役割ごとに音高、長さ、再生位置を表示します。役割の視覚的な識別は機種をまたいで固定し、ミュート／ソロを用意します。機種のアクセント色を変えても全役割を塗り直しません。

音楽上の役割とハードウェアのボイスは区別します。特にC64では4役割が独立した4ボイスを意味しません。共有状態を正しく表示します。メーターは実測音量を使い、予定された音符のアニメーションを実測波形と呼びません。

小さな幾何学的キャラクターは任意の表現であり、完成の前提ではありません。動きは音に反応し停止に従います。動きを減らす設定でも、音符とボイスの所有状態を読み取れるようにします。

<a id="arcade-effects"></a>
### アーケード効果音

Jump、Coin、Laser、Explosionの大きなラベル付きパッドを用意します。マウス、タッチ、明示されたキーボード操作に対応し、各機種に適した音色を使います。音と画面の反応は同じイベントから起動します。

小さな場面や短い表示変化で効果を伝えます。ゲーム全体を作る必要はありません。中心となる実演は、ボイスの借用と復帰を耳で確認できることです。長押し連打や複雑な場面は後の磨き込みです。

<a id="simple-music-creation"></a>
### 簡単な作曲

最初から再生できる曲を置きます。Editでメロディを高さで編集する画面とドラムのステップグリッドを開きます。選択パターンは楽譜全体への窓であり、他のパターン、順序、和音、意図を失いません。各役割の音色は既存の意図カタログから選びます。

タッチで試聴し、音階補助モードと半音階へのアクセスを両立します。初期のライブ試聴はタッチ／キーボードの8音パレットで行い、その演奏をループに録音する機能は後続です。

携帯では読みやすい全体図と十分な広さの編集領域を用意します。16ステップを収めるために操作対象を縮めません。スクロールやピンチで誤って音符を書かないようにします。キーボード操作、Undo／Redo、ローカル下書きの自動復元を提供します。テキスト／トラッカー表示は上級者向けとして残し、入力途中の不完全な文を保持して、適用前に検証します。

<a id="share-and-reveal-the-library"></a>
### 共有とライブラリの紹介

共有先では編集済みの全曲と選択機種を復元します。公開とローカル下書きを区別し、再生前にタイトルやアカウントを要求しません。

View codeで現在の移植可能な楽譜と最小の実行例を表示し、機種と意図を保持します。楽譜、コードのコピーと音声ダウンロードを提供し、実例と出力が編曲済みの曲を再現することを確認します。V1が保存するのは楽譜の編集であり、未録音のライブ効果音演奏まで共有したように見せません。

音声資産のエンジン／アレンジャー／プロファイルの識別を定義します。曲のURLを安定させ、レンダリングされたバイト列を版管理するか、変更可能な音声を明示的に再検証します。不変キャッシュの同一識別子に異なる音を隠しません。必要なステレオと正しい機種メタデータを保持します。

<a id="visual-direction"></a>
## 視覚的な方向

コンパクトで触れたくなる音楽機器を目指します。大きな操作部、明確な押下状態、暗い動的ディスプレイ、制御された強い色、読みやすいラベルを使います。ピクセルアートは表示の細部に使い、全ラベルに強制しません。動きは音、所有状態、操作を伝えるために使い、無関係な装飾、長い宣伝文、技術設定の壁を避けます。

筐体の色や図柄、形は最初の動く画面で検証する実装上の選択です。音の出る試作を遅らせる理由にはしません。既存のフレームワークと音源コアを維持します。

<a id="build-order"></a>
## 実装順序

<a id="a-repair-the-two-foundations-the-demo-depends-on"></a>
### A. デモの前提となる2つの基盤を修復

- API読み込み、編集状態、再生、フォークで楽譜全体を保持します。タイトルだけの変更で音楽フィールドを変えず、不変の公開データを守ります。
- 予定された音楽命令を明示的な所有権付きでキャンセル可能にします。Stop後は無音を維持し、待機中の曲が効果音を上書きしないようにし、終了後の復帰を定義します。ボイス間の共有レジスタも扱います。
- 実際のレジスタ書き込み／音声と楽譜内容を観測する回帰テストを追加します。ベースラインがない場合、適合性コマンドは失敗させます。

一般的なエンジンの作り直しではなく、範囲を絞った修復です。通過したら直ちに画面の楽器を作ります。

<a id="b-deliver-the-first-playable-screen"></a>
### B. 最初の遊べる画面を届ける

親しみのあるメロディ、初回操作での再生、公開4機種の切り替え、反応する4レーン、4効果音パッドを提供します。切り替え中の位置と実際のボイス中断を表示し、本番ビルドでブラウザの音声ライフサイクル、初回操作、携帯操作を確認します。

<a id="c-complete-the-v1-loop"></a>
### C. V1の流れを完成させる

簡単な編集、意図の選択、試聴パレット、Undo／Redo、下書き復元、共有、コード／楽譜出力、一貫した音声ダウンロードを揃えます。テキスト入力も修復し、一時DBを使った主要Web操作をCIへ追加します。

最初の遊べる段階から初音、機種比較、編集、効果音、共有を測定し、楽譜内容と個人情報は収集しません。実際の利用観察を併用し、数値目標は基準測定後に設定します。

<a id="d-expand-after-testing-the-demo"></a>
### D. デモを試してから拡張する

最初の後続機能は**タップ録音**です。Recordは必要なら再生を開始し、音符パレットとドラムのタップを音声時計上の最寄り16分音符へ重ね録りします。離した時点ではなく押下時点を採用します。長さの異なるパターンと反復を含む曲順全体を扱います。

1テイクを1回のUndoとし、録音済み編集は到着ごとに下書きへ保存します。Finish takeまでは伴奏楽譜を変えず、終了時に更新済み楽譜を1回だけ読み込みます。録音中の表示は伴奏に従います。テンポ、機種、ミュート／ソロ、楽譜の直接置換をロックし、役割と試聴音階は変更できます。Stop、Undo、タブ離脱で録音を終了します。アーケード効果音はライブ試聴であり、楽譜には録音しません。

タップの長さは既存グリッドと同じく次の音符／カットまでです。長押し時間の記録、自由時間の音声録音、メトロノーム／カウントインは初期範囲外です。スキーマ移行や実行時依存の追加は不要です。`Chip.quantizedPosition()`で同じグリッド位置計算をライブラリ利用者にも公開します。

- 8音パレットからの量子化ライブ録音と重ね録り。
- Surprise me：役割をロックしながらメロディ、ドラム、音色を変奏しUndo可能にします。まず作曲済み／規則ベースの変奏を使い、再生にリモートAIを要求しません。
- 豊かな編曲：SNES三和音、FMドラム、SIDフィルター。見た目だけ同じ汎用効果ではなく実際の機能を公開します。
- MIDI入力、ステム、全5機種の一括出力。
- 利用実績に応じた追加曲、効果音、新機種。

<a id="other-audit-work"></a>
## 監査のその他の作業

匿名で遊ぶデモの前提としてアカウントシステムを作り直す必要はありません。ただしログイン／ライブラリ復元に依存する前に、永続的な利用者ID、APIキー、ブラウザセッションを分離します。ログインリンクの消費でエージェントのAPIキーを失効させません。レンダリング制限、移行、低サンプルレートのオフライン予約、文書整合性とともに追跡します。

V1の聞こえ方、楽譜の保持、共有出力を優先します。MIDI、完全なゲーム／DAW、共同編集、大規模ギャラリー、広範なDSP書き直し、新チップはV1外です。アニメーションが動くことを根拠に既知の音声不具合が直ったと主張しません。

<a id="acceptance"></a>
## 受け入れ条件

- アカウント、チュートリアル、音名の知識なしで音を出し、機種を比較して効果音を鳴らせること。
- 機種切り替えで楽譜と位置を保持し、Stop後に勝手に音が復帰せず、表示する効果音の所有状態が実音と一致すること。
- 複数パターンの楽譜でタイトルだけ変えても全音楽フィールドをフォークに保持し、再生と出力も同じ楽譜を使うこと。
- タッチスクロールで編集せず、キーボードと携帯で操作でき、テキスト入力、Undo、再読み込み復元が正しいこと。
- 共有リンクと実行例が、文書化したレンダリング版の契約内で現在の編曲を再現すること。
- 本番ビルドの自動検査で結果を検証すること。再生操作はUIフラグや`canPlay()`だけでなく、音声／レジスタ出力を測ること。
- 広い対応を主張する前にChromium、Firefox、Safariの音声と実機携帯のタッチを確認し、制限を記録すること。

音楽未経験者がもう1つボタンを押したくなり、開発者がコードをコピーしたくなるデモにします。

<a id="creative-and-api-follow-up-acceptance"></a>
## 作曲機能とAPIの後続受け入れ条件

次の統合単位はP8-23、P8-11、P8-12、AUD-1/2/4/5/6です。

- シード付きローカル変奏でロック役割を保持し、1回でUndoできること。
- MIDI権限はConnect時だけ要求すること。入力は録音と共通化し、離鍵を無視し、チャンネル10のドラムを対応付け、切断後に停止すること。
- キャンセル可能なワーカー出力でWAV、位置の揃った独立ステム、全5機種、対応VGMを提供し、ZIPには楽譜を含めること。
- 公開音声に時間、同時実行、キャッシュ、頻度の上限と条件付きGETを設け、削除された公開曲をキャッシュから復活させないこと。
- ブラウザログイン、キー交換、失効でも所有権を維持し、同一マジックリンクの同時消費は1件だけ成功すること。
- 旧DB／新DBの移行と失敗時ロールバックを検証し、公開JSONにアカウントIDや認証秘密を出さないこと。
- 表現できない基音とアルペジオの極値を診断し、実装済み編曲、将来作業、実機の証拠を文書で区別すること。

実機MIDI／携帯の遅延、代表端末のCPU／GC、分散クォータ、新チップ、P8-13の豊かな編曲は別作業です。

<a id="japanese-console-entry-september-2026"></a>
## 日本版コンソールを入口にする（2026年9月）

ホームはJavaScript音源チップの遊べるデモです。最初の画面で目的を説明し、マリオ／ゼルダ／ソニックとPlayを並べます。オリジナル曲はMore to playへ、作曲と出力はコンソールの後へ置きます。保存下書きも共有楽譜もない場合だけマリオを初期選択します。

共通の選択部はファミコン、ゲームボーイ、メガドライブ、スーパーファミコンの日本版画像を色付き・表示キャプションなしで使います。アクセシブル名、ツールチップ、押下状態は残します。`DEMO_MACHINES`でC64を表示層だけから隠し、スキーマ、SDK、古い下書き、5機種の検証は維持します。出典とチェックサムは`apps/web/public/machines/README.md`にあります。

コンソールへの初回操作で1度だけ音楽を開始します。最初に曲／機種を変えた場合、新楽譜を音声フックへ直接渡し、古いReact描画が以前の選択を再生しないようにします。AudioContextの作成とresumeは信頼された操作内で同期的に行います。表示だけ、ナビゲーションリンク、Tab移動では鳴らしません。Stopもこの1回の開始意図を消費し、その後の編集で再開しません。未対応／ブロック時はエラーとPlayを表示します。試聴ラボは明示的なPlayと遅延ロスレス取得を維持し、親しみのある曲を先頭に、マリオ／スーパーファミコンを初期選択します。Aboutでは録音比較とライブ合成の違いを説明します。

<a id="readable-type-and-attribution"></a>
## 読みやすい文字とクレジット

共通文字サイズは`apps/web/src/ui/tokens.css`に置きます。ラベル0.875rem、本文1rem、節見出し1.5rem、ページ見出し2–2.75remとし、場当たり的なpx指定を避けます。携帯では操作部とナビゲーションを折り返し、ブラウザ標準文字サイズでラベルを14px未満にしません。入力は16pxを保ちます。共通フッターは https://gwendall.com へのリンク付きでMade by gwendallと表示します。
